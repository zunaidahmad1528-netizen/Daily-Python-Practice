# Daily Python Practice
 
A daily Python practice repo — one topic at a time, one file at a time. Written for my own learning, but structured so anyone can follow along and learn Python from it too.
 
## Why This Repo Exists
 
I started this because watching tutorials alone wasn't working. I'd finish a video, feel like I understood everything, and forget it all by the next day. So now I code every day and push whatever I write here. Months later, this repo will show exactly how much I've learned — and it might help you learn the same things along the way.
 
## Who This Is For
 
- Beginners who want to see real, working examples of Python topics instead of just theory
- Anyone who learns better by reading and running simple code than by watching long tutorials
- Self-learners who want a day-by-day structure they can copy for their own practice
## What's Inside
 
Each file focuses on one topic, with simple, well-commented code you can read top to bottom.
 
| File | Topic |
|------|-------|
| `01_basics.py` | Variables and data types |
 
More files will be added regularly as new topics are covered. There's no fixed syllabus — each day covers whatever topic comes next, but always beginner-friendly and self-contained.
 
## How to Use This Repo to Learn
 
1. Open a file, e.g. `01_basics.py`
2. Read the code and comments before running it — try to guess what it does
3. Run it yourself and compare with what you expected
4. Try changing values or adding your own lines to test your understanding
## How to Run
 
No setup, no dependencies — just plain Python files.
 
```bash
git clone <repo-url>
cd daily-python-practice
python 01_basics.py
```
 
## Why I'm Doing This
 
Honestly, I just want to stop being a beginner. The only way that happens is by writing code regularly, breaking things, and figuring out how to fix them. If this repo helps someone else do the same, even better.
